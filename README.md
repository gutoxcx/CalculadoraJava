# Calculadora Java

calculadora simples em **java** desenvolvida para praticar lógica de programação, estruturas de controle e laços de repetição (`while`).

---

## 🚀 funcionalidades
- operações básicas: adição (+), subtração (-), multiplicação (*) e divisão (/)
- verificação de divisão por zero
- loop com opção de sair digitando `q`

---

## 📦 como executar
1. clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/nome-do-repo.git


2. entre na pasta do projeto:

   ```bash
   cd CalculadoraJava
   ```
3. compile o arquivo java:

   ```bash
   javac CalculaJava.java
   ```
4. execute o programa:

   ```bash
   java CalculaJava
   ```

---

## 📚 objetivo

este projeto foi feito para **treinar lógica e uso de estruturas de controle** em java.
é um exercício simples, mas uma boa base para evoluir para projetos mais complexos.
